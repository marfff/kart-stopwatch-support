FREE HOSTING USING GITHUB PAGES
1. Sign into github.com and create a new PUBLIC repository named kart-stopwatch-support.
2. Upload ALL FIVE website files into the repository root (do not upload the ZIP itself).
3. Open repository Settings > Pages. Under Build and deployment choose Deploy from a branch; select main and /(root); Save.
4. After publishing, the public URLs will follow this structure (replace YOUR-USERNAME with your actual GitHub username):
   https://YOUR-USERNAME.github.io/kart-stopwatch-support/
   https://YOUR-USERNAME.github.io/kart-stopwatch-support/privacy.html
   https://YOUR-USERNAME.github.io/kart-stopwatch-support/support.html
5. Open each actual URL in a private browser window before entering in App Store Connect.
